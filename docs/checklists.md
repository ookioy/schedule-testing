# Чеклісти для тестування

## Модуль: [Назва модуля вашого варіанту]

### Функціональність
- [ ] Перевірка відображення списку аудиторій (наприклад, I-18, I-19, 1-21) у шапці таблиці.

- [ ] Перевірка відображення номерів пар (1, 2...) у першому стовпці.

- [ ] Перевірка підсвічування комірки яскраво-зеленим кольором при 0 занять.

- [ ] Перевірка підсвічування комірки зеленим кольором при наявності 1 заняття.

- [ ] Перевірка підсвічування комірки червоним кольором при наявності >1 заняття (конфлікт).

- [ ] Перевірка зміни дня тижня (наприклад, відображення для Понеділка).

### Негативні сценарії
- [ ] Перевірка відображення таблиці, якщо в системі не додано жодної аудиторії.

- [ ] Перевірка поведінки системи при спробі відобразити розклад на вихідний день (якщо пари не передбачені).

- [ ] Перевірка відображення довгих назв предметів/викладачів у тултіпі (чи не виходить текст за межі).

- [ ] Перевірка роботи інтерфейсу при втраті інтернет-з'єднання (Retry mechanism).

### UI/UX
- [ ] Перевірка наявності та коректності роботи кнопки перемикання мов (UA/EN) у верхньому правому куті.

- [ ] Перевірка відповідності вибраного радіобаттона «Розмір стовпців» фактичному вигляду таблиці.

- [ ] Перевірка доступності переходу до інших розділів («Пари», «Розклад», «Управління посиланнями») через бокове або верхнє меню.

- [ ] Перевірка читабельності тексту номерів пар та назв аудиторій на білому фоні.

- [ ] Перевірка адаптивності таблиці при зменшенні ширини вікна браузера.
